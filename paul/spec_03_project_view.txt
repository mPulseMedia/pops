SPEC 03 Project View

1.  Overview
    A.  Project view: grid of all decks; each deck shows
        as small card with title. body class: project-view.
    B.  Layout: card-rect overlay with getStatesForAllDecks
        ("project"); setProjectStackOrder per deck.
    C.  Deck titles: centered above each deck; width
        33.333vw (match viewport), max-width 100%; 100%
        on mobile (single column).
    D.  Title row: Load, Export, Reload, Auto-reload visible;
        Back and Expand hidden. See spec_01 ux.txt.

2.  User actions and code

    A.  Open deck (→ Deck view)
        1.  User: click deck, deck viewport, deck title, or
            card rect.
        2.  Effect: setActiveDeck(id); setView("deck");
            runProjectDeckTransition("deck").
        3.  Code: deck click; viewport click (project-view
            only); deckTitle click (when not deck/expanded);
            setupCardRectClicks on .card-rect (project-view
            branch).

    B.  Load deck data
        1.  User: click Load (📂).
        2.  Effect: file picker; loadDeckDataFromFileInput.
        3.  Code: loadDeckDataFileBtn → loadDeckDataFileInput
            click; change handler.

    C.  Export deck data
        1.  User: click Export (↓).
        2.  Effect: exportDeckDataToFile; download JSON.
        3.  Code: exportDeckDataBtn click.

    D.  Reload deck data
        1.  User: click Reload (↑).
        2.  Effect: reloadDeckDataFromFile; fetch index.txt.
        3.  Code: reloadDeckDataBtn click.

    E.  Auto-reload toggle
        1.  User: click Reload switch.
        2.  Effect: index-card3-auto-reload "0" | "1".
        3.  Code: reload_switch click; update_reload_ui.

3.  Key functions

    A.  applyView("project"): body project-view; pageTitle
        "Project"; getStatesForAllDecks("project");
        setProjectStackOrder(activeDeckIndexForLayer).
    B.  getStatesForAllDecks("project"): project layout per
        deck.
    C.  setProjectStackOrder(activeDeckIndexForLayer): z-index
        for card rects in project grid.
    D.  loadDeckDataFromFileInput, exportDeckDataToFile,
        reloadDeckDataFromFile: data I/O.

4.  Cross-view (shared)
    A.  Text editing disabled in project-view (dblclick
        returns early). See spec_02 §5.
    B.  Image lightbox: card-text-image click works in
        deck/expanded only (project-view returns early).
